# 📊 Дашборд: Процесс разработки программного обеспечения

## Описание проекта

Интерактивный веб-дашборд для анализа ключевых метрик процесса разработки программного обеспечения, созданный с использованием библиотеки Dash (Python).

## Функциональность

Дашборд включает **5 интерактивных элементов визуализации**:

### 📈 График 1: Динамика завершенных задач (Временной ряд)
- **Назначение**: Отображает тренд завершенных и активных задач во времени
- **Тип**: Линейный график с маркерами
- **Интерактивность**: Наведение курсора показывает точные значения, масштабирование, панорамирование
- **Расположение**: Верхний левый блок

### 🥧 График 2: Распределение по фазам разработки (Круговая диаграмма)
- **Назначение**: Визуализация структуры распределения работ по фазам (Планирование, Разработка, Тестирование, Релиз)
- **Тип**: Круговая диаграмма (Pie chart) с центральным отверстием
- **Интерактивность**: Подсветка сегментов при наведении, отображение процентов
- **Расположение**: Верхний правый блок

### 📊 График 3: Сравнение часов по активностям (Гистограмма)
- **Назначение**: Анализ распределения рабочих часов между Code Review, Тестированием и Разработкой
- **Тип**: Группированная столбчатая диаграмма (Bar chart)
- **Интерактивность**: Наведение для точных значений, переключение видимости категорий
- **Расположение**: Средний левый блок

### 🔍 График 4: Корреляция Velocity и качества кода (График рассеяния)
- **Назначение**: Анализ зависимости между скоростью разработки (Velocity) и качеством кода
- **Тип**: Scatter plot с размером точек по количеству задач
- **Интерактивность**: Цветовая кодировка по фазам, подробная информация при наведении
- **Расположение**: Средний правый блок

### 📋 График 5: Таблица ключевых метрик
- **Назначение**: Детальное отображение численных показателей за выбранный период
- **Тип**: Интерактивная таблица с пагинацией
- **Интерактивность**: Сортировка по столбцам, постраничная навигация (10 записей на странице)
- **Расположение**: Нижний блок

## Дополнительные интерактивные элементы

### 🎛️ Выпадающий список "Период анализа"
- Выбор периода: Все периоды, Квартал 1-4
- Автоматическая фильтрация всех графиков

### 🎛️ Выпадающий список "Фильтр по фазе"
- Множественный выбор фаз разработки
- Динамическое обновление визуализаций

### 📊 KPI-индикаторы (Панель ключевых показателей)
- Всего задач завершено
- Средний Velocity (Story Points)
- Среднее качество кода (%)
- Количество исправленных багов

## Установка и запуск

### Требования
- Python 3.8+
- pip

### Шаг 1: Клонирование репозитория
```bash
git clone https://github.com/your-username/software-dev-dashboard.git
cd software-dev-dashboard
```

### Шаг 2: Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 3: Запуск приложения
```bash
python app.py
```

### Шаг 4: Открытие в браузере
Перейдите по адресу: **http://127.0.0.1:8050**

## Использование

1. **Загрузка данных**: 
   - Нажмите на область "📁 Загрузка данных" или перетащите CSV файл
   - Поддерживаемый формат: `software_dev_data.csv`
   - После успешной загрузки появится сообщение с количеством записей

2. **Фильтрация данных**:
   - Выберите период анализа из выпадающего списка (весь год или конкретный квартал)
   - При необходимости укажите интересующие фазы разработки

3. **Анализ метрик**:
   - Изучите KPI-индикаторы в верхней части дашборда
   - Просмотрите динамику показателей на графиках
   - Наведите курсор на элементы для детальной информации

4. **Работа с таблицей**:
   - Прокрутите до нижней части страницы
   - Используйте кнопки пагинации для навигации

## Структура данных (CSV)

Файл `software_dev_data.csv` должен содержать следующие колонки:

| Колонка | Описание | Тип данных |
|---------|----------|------------|
| Дата | Дата записи | Date (YYYY-MM-DD) |
| Месяц | Название месяца | String |
| Завершенные_задачи | Количество завершенных задач | Integer |
| Активные_задачи | Количество активных задач | Integer |
| Баги_найдено | Количество найденных багов | Integer |
| Баги_исправлено | Количество исправленных багов | Integer |
| Code_Review_часов | Часы на Code Review | Integer |
| Тестирование_часов | Часы на тестирование | Integer |
| Разработка_часов | Часы на разработку | Integer |
| Velocity_SP | Velocity в Story Points | Integer |
| Качество_кода_% | Процент качества кода | Float |
| Покрытие_тестами_% | Процент покрытия тестами | Float |
| Технический_долг_часов | Часы технического долга | Integer |
| Категория_фазы | Фаза разработки | String |

## Ветки Git

- **development** - ветка разработки (основная рабочая ветка)
- **release** - ветка релиза (стабильная версия)
- **main** - главная ветка

## Workflow Git

1. Разработка ведется в ветке `development`
2. Регулярные коммиты при добавлении функционала
3. После тестирования изменения мержатся в `release`
4. Стабильные релизы мержатся в `main`
